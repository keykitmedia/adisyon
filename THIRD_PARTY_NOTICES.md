# Üçüncü taraf bileşenler

| Bileşen | Kullanıldığı yer | Lisans |
|---|---|---|
| [node-postgres (`pg`)](https://github.com/brianc/node-postgres) | Vercel sürümünde veritabanı bağlantısı | MIT |
| [Electron](https://github.com/electron/electron) | Mac ve Windows masaüstü uygulaması | MIT; içerdiği Chromium bileşenlerinin lisansları paketlenen uygulamadaki `LICENSES.chromium.html` dosyasındadır |
| [@electron/packager](https://github.com/electron/packager) | Yalnızca uygulamayı paketlerken | BSD-2-Clause |
| Barlow, Barlow Condensed | Arayüz yazı tipi | SIL Open Font License 1.1 |
| IBM Plex Mono | Rakam ve fiş yazı tipi | SIL Open Font License 1.1 |
| Doto | Müşteri ekranı yazı tipi | SIL Open Font License 1.1 |

Yazı tipleri değiştirilmeden, `site/fonts/` klasöründen sunulur. Lisans metni ve
telif bildirimleri `site/fonts/OFL.txt` dosyasındadır. Yazı tipleri ayrı olarak
satılmaz.
